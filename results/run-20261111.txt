Known script gaps found in this run (this run used src/ BEFORE the fixes below)
  - src/storage_info.summarize() printed only totalStorageBytesUsed, because it did
    not read the nested {sizeInBytes, count} response shape. The per-component table
    above was built from the raw response.
  - src/index_rebuild.with_backoff() did not cover client-side ReadTimeoutError.
  Both were fixed in src/ after this run. summarize() now walks the nested shape
  (using dictionaries.total so blobs are not double-counted), and with_backoff()
  now retries ReadTimeoutError and ConnectTimeoutError. The numbers in this file
  are unaffected.
